# TAMS Lab Website

Visit the [TAMS Lab website](https://chentangmark.github.io/lab/).

Lab members can submit website updates through pull requests to this repository. Chen reviews changes before they are published. See [Contributing](CONTRIBUTING.md) for instructions.

## Where to make changes

| Content | Source |
| --- | --- |
| Lab members | [`_data/lab_members.yml`](_data/lab_members.yml) |
| Lab news | [`_data/lab_news.yml`](_data/lab_news.yml) |
| Research | [`_data/lab_research.yml`](_data/lab_research.yml) and [`_pages/lab/research/`](_pages/lab/research/) |
| Publications and paper links | [`_bibliography/papers.bib`](_bibliography/papers.bib) |
| Publication thumbnails | [`assets/img/publication_preview/`](assets/img/publication_preview/) |
| Lab photos | [`_data/lab_photos.yml`](_data/lab_photos.yml) and [`assets/img/lab/`](assets/img/lab/) |
| Other lab pages | [`_pages/lab/`](_pages/lab/) |

The site uses Jekyll and the [al-folio](https://github.com/alshedivat/al-folio) theme. This repository shares its source with Chen's personal website, so some data and layouts affect both sites.
